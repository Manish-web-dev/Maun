# तिम्रो लागि ♡

A small, three-page birthday website. It uses plain HTML, CSS, and JavaScript, so it can be hosted directly with GitHub Pages.

## Make it yours

- Keep `love.mp4` in the project root. It plays muted and loops as the background on all three pages.
- Keep `birthday wish tune.mp3` and `2nd.mp3` in the project root. The first page attempts to autoplay the birthday track; the letter and memories pages attempt to autoplay `2nd.mp3`. Use the sound button to mute or unmute.
- Add your photos to the `images` folder with these names: `photo-1.jpg`, `photo-2.jpg`, and `photo-3.jpg`.
- Edit the Nepali message in `wishes.html` and the photo captions in `memories.html` to make them personal.

## Pages

- `index.html` — birthday welcome, balloons, and animated sparkles
- `wishes.html` — your birthday letter
- `memories.html` — photo gallery and closing message

## Publish with GitHub Pages

Push this folder to a GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the branch you pushed and its root folder, then save. The site starts at `index.html`.
